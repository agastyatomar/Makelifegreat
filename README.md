# MakeLifeGreat — Aadi's Personal Life OS

MakeLifeGreat is an offline-first Android life-management app customized for **Aadi**.

## Core areas

- Wake-up and sleep routines
- School/class schedule
- Study and focus sessions
- Tasks and reminders
- Notes and goals
- Running and home workouts
- Progress tracking
- App blocking and distraction control
- DND/focus scheduling where Android permits it
- Local backup/restore
- Local music integration

## Privacy and safety

The core experience is designed to work locally on the device. No mandatory account is required. Permissions are requested only for features that need them.

Android security restrictions are respected. MakeLifeGreat does not bypass passwords, authentication, DRM, app locks or system security.

## Build the APK

GitHub Actions builds APKs automatically. Open **Actions**, choose **Build Debug APK**, run it manually, then download the `MakeLifeGreat-debug-apk` artifact.

For release builds see [docs/BUILD.md](docs/BUILD.md) and [docs/SIGNING.md](docs/SIGNING.md).
