# MakeLifeGreat Feature Specification

## Daily life
- Dashboard
- Today's schedule
- Recurring routines
- Alarms and reminders
- Daily completion tracking

## School and study
- School timetable
- Class blocks
- Study periods
- School mode
- Focus sessions
- Subjects and study progress
- Legitimate launch/shortcut support for study apps

## Productivity
- Todo list
- Notes
- Goals
- Progress statistics

## Fitness
- Running sessions
- Home workouts
- Exercise counters
- Workout history
- Optional Health Connect integration

## Focus and sleep
- Focus sessions
- App blocking
- App groups
- Usage tracking
- Sleep schedule
- Wind-down
- Wake-up alarms
- DND integration where Android permits it

## Music and data
- Local device music integration
- Android media controls
- Room local database
- DataStore
- JSON backup/restore
- Offline-first core
