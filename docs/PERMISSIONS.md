# Android Permissions & Limitations

MakeLifeGreat requests only permissions required by enabled features.

**Notifications:** required for modern Android notifications.

**Exact alarms:** may be required for highly reliable scheduled alarms.

**DND:** requires Notification Policy Access and user approval.

**Accessibility:** used only for legitimate foreground-app detection/blocking and requires explicit user enablement. It is not used to bypass authentication or security.

**Usage access:** required for usage statistics.

**Fitness:** supported sensors or Health Connect may be used when available.

**Airplane mode:** modern third-party apps cannot silently control all radio settings, so MakeLifeGreat uses user-guided actions instead of security bypasses.
